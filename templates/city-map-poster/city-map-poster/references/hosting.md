# Hosting
One self-contained HTML file; no external URLs, tiles or storage; system fonts only. SAMPLE_SITE_CSP: sandbox allow-scripts; default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data: blob:; font-src data:; media-src data: blob:; connect-src 'none'; form-action 'none'; base-uri 'none'; frame-ancestors 'self'. The host iframe only needs allow-scripts. Drawing is Canvas 2D on the main thread with Path2D and OffscreenCanvas; no WebGL or Web Worker.
URL parameters: lang (en or zh-CN), embed=1, quality=low|high (low draws at one device pixel), capture=1. Compact mode (embed=1, or a window narrower than 1180 or lower than 520 px) shows the poster and a one-row strip: play, next kind, next theme, format, round map, zoom out, zoom in and redraw.
Capture uses window.__scene with slug, version, ready, inspect, act, pointer, press, release, cover, film and exportPoster({ kind, landmark, theme, format, shape, width }) → PNG data URL; capture=1 adds step and script. act takes play, pause, kind (map, skyline, food, landmark or next, and a landmark index), landmark (the next one), theme (index, id or next), shape (full, circle or toggle), format (portrait, square, landscape or next), pan (metres east and north), zoom (factor), draw and marks. script(t) draws the film frame at t from poster.json and style.json alone. Embedded pages post city-map-poster:ready, or city-map-poster:error with code webgl when the 2D canvas cannot start (code data for unreadable map data).
