# Miniature city diorama scene

Build an interactive 3D miniature of {{city}} on a floating tabletop tray, with dedicated landmark models and camera views for: {{landmarks}}. The reference scene in this Skill is Manhattan; for another city replace the outline, the street plan, the landmark models, the views and the copy together, not only the names. Plan reserved landmark sites first, then a connected road graph, blocks and parcels, then ordinary buildings from at least ten distinct families; traffic, pedestrians and boats use the same road graph. Author all geometry as procedural, instanced Three.js code; do not download models, textures or HDR files. Palette: {{palette}}. Interface: {{ui}}. Brand: {{brand}}. Interactions: {{interaction}}.

Day and night must change real scene lights, sky, fog, water and window emission together, not only a background color. Camera flights consume OrbitControls damping first and never end inside a building. Run every clock from one virtual time step so a capture mode (`?capture=1`) can step frames and play a deterministic cover script. Provide the full 16:9 composition for desktop and the cover, a compact layout for phones and a 345 by 345 embed, English and Simplified Chinese UI, reduced motion (camera cuts) and a single offline HTML with no runtime network, storage or model calls. Hide downloads, pop-ups and fullscreen inside a sandboxed frame. State that the layout is compressed and interpretive, not a survey.

Stack (pinned): Vite 7.3.7, React 19.3.1, TypeScript 5.9.3, three 0.186.1, playwright-core 1.64.1 with the system Chrome for verification, the system FFmpeg for recording. Read the relevant sections of `references/accepted-brief.en.md` (planning, architecture families, landmarks, street life, materials) before changing the city.
