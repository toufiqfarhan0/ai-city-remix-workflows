# Hosting
One self-contained HTML file; no external URLs, tiles or storage; system fonts only. SAMPLE_SITE_CSP: sandbox allow-scripts; default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data: blob:; font-src data:; media-src data: blob:; connect-src 'none'; form-action 'none'; base-uri 'none'; frame-ancestors 'self'. The host iframe only needs allow-scripts. Drawing is Canvas 2D on the main thread; no WebGL or Web Worker.
URL parameters: lang (en or zh-CN), embed=1, quality=low|high, capture=1. Compact mode (embed=1, or a window narrower than 900 or lower than 520 px) shows the city with the landmark name and a one-row strip: play, zoom out, zoom in, turn, light, next landmark and labels.
Capture uses window.__scene with slug, version, ready, inspect, act, pointer, press, release, cover and film; capture=1 adds step and script. act takes play, pause, pan (metres east and north), zoom (factor), rotate (direction), time (0–1), landmark (index or next) and labels. script(t) draws the film frame at t from area.json and style.json alone. Embedded pages post pixel-iso-city:ready, or pixel-iso-city:error with code webgl when the 2D canvas cannot start (code data for unreadable area data).
